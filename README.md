# Ayushi Jha · Portfolio

Personal portfolio of Ayushi Jha, Senior Technical Writer in Bengaluru.

Live site: https://ayushijha04.github.io/Github-Portfolio/

## Edit the site

Everything is in one file, `index.html`. Open it in any editor, change the text, and commit.
GitHub Pages republishes the site within a minute or two.

- Text sections are marked by their headings (Overview, Impact, Featured project, Release notes, Skills and tools, Certifications, Contact).
- To add a job, copy one `<li class="entry">` block in Release notes and change the dates and text.
- Colors and fonts are at the top of the `<style>` block.
