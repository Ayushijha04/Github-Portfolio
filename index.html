#Featured project

Internal innovation project · Oracle Logistics Cloud · 2023 to 2025

LogiDoc.AI: AI-assisted documentation for logistics APIs

I designed and led an AI-assisted documentation platform for Oracle Logistics Cloud APIs, working with product managers, UX writers and engineers across India, North America and EMEA.

AI writing workflows

Generative AI (Vertex AI and OpenAI) drafted SDK examples, parameter definitions and onboarding guides based on how the APIs were used.

Try-it API playground

Swagger UI with mock data, so developers could test APIs like Order Fulfillment and Shipment Tracking without a full backend.

Search that finds things

A React interface with Algolia search and clear information architecture, which lifted content engagement by 40%.

Translation pipelines that kept terminology consistent, plus video tutorials and visual workflows alongside the written docs.
